## Ложные тревоги (сняты сверкой — не чинить)

- **CORS в dev-связке не нужен**: фронт ходит через Vite-proxy (тот же origin).
- **«vitest 64 против 63 it»**: цикл TZ-тестов даёт два теста из одного блока —
  счёт совпадает.
- **«4/4» (шаг 4.1) против «6/6» (шаг 4.2)**: корректные снимки разных дат.
- **`getEventType` «мёртвый код»**: используется в трёх местах (слоты, POST
  типов, POST броней).
- **`UNIQUE`-индекс как backstop пересечений**: инвариант — «нет пересечения
  интервалов», уникальность ключа его не выражает; гарантия — один процесс
  (задокументировано в decision-guide).
- **bump-флаги release-please**: не конфликтуют, а комбинируются; после 1.0.0
  оба неактивны — вопрос косметики конфига.
- **`actions/cache`**: установка ~1–2 мин/джоб, кэш в container-джобах — лишний
  механизм без выигрыша на текущем графе.
